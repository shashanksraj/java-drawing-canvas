# Java Drawing Canvas

An interactive drawing application built in Java that allows users to create and render shapes using mouse input.

## Features
- Draw shapes dynamically using mouse interactions
- Object-oriented shape hierarchy (Line, Rectangle, Oval)
- Real-time canvas updates
- Modular design with reusable components

## Tech Stack
- Java
- Object-Oriented Programming (OOP)
- Basic GUI rendering

## Project Structure
- `src/` → Core application logic and shape classes
- `DrawingCanvas.java` → Main rendering and interaction logic
- Shape classes → Handle drawing and structure of objects
